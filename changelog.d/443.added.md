- `mcp-hash`, `mcp-pin` and `mcp-verify` accept an opt-in `--connect` flag that launches one named local stdio MCP server from the project config and reads its live `tools/list`, so runtime tool pinning no longer needs a manual pipe. A scan still never spawns a server. Each launch needs per-run consent (an interactive `[y/N]` or `--yes`; no terminal and no `--yes` refuses with exit `2`), prints the exact argv, working directory and env keys first, runs with a minimal environment, refuses relative commands or scripts that escape the project through a symlink, and kills the process tree after the list is read or after 15 s (`RIGSCORE_CONNECT_TIMEOUT_MS` overrides). A timeout or malformed reply exits `5`.
